Abstract

India operates a vast ecosystem of public-facing web portals, along with numerous servers and digital platforms. Given the scale and continuous evolution of this landscape, maintaining consistent visibility and oversight across all assets at all times remains a significant challenge. As per our research we observed a recurring and concerning trend: live public domains with database credentials exposed in publicly accessible .env files, servers with openly available .git repositories, and sensitive information such as Aadhaar and PAN numbers embedded in downloadable PDFs accessible to anyone. These weren't sophisticated attacks; they were basic hygiene failures which were missed.

This led us to build CyberDrishtiX. It continuously monitors public web portal domains discovering assets through Certificate Transparency logs, scanning for credential leaks and PII exposures, running GitHub searches for accidentally committed secrets.

The more significant challenge was not detection but establishing trust. In an audit context, tools that generate a high volume of unvalidated findings can reduce effectiveness and confidence in the results. To address this, we embedded accuracy validation directly into the workflow: every AI-flagged observation undergoes analyst review prior to disclosure, and we continuously track true positive and false positive rates against defined quality thresholds.

Keywords: Cyber Hygiene Monitoring, Public Web Asset Exposure, Credential Leak Detection, PII Exposure Risks, .env File Misconfiguration, Git Repository Security, Certificate Transparency Log Monitoring, Automated Security Scanning, False Positive Reduction, Continuous Attack Surface Monitoring

About the Project

CyberDrishtiX (साइबर दृष्टि), featured in the projects section of this site, is an AI-assisted platform for continuous attack surface monitoring of public web portals, built for large-scale national cyber audit operations. As described in the abstract, it:

  • Discovers assets through Certificate Transparency logs.
  • Scans for credential leaks and PII exposure on public domains, including exposed configuration files, open repositories, and sensitive data in downloadable documents.
  • Searches GitHub for accidentally committed secrets.
  • Validates before disclosing: every AI-flagged observation goes through analyst review, and true positive and false positive rates are tracked against defined quality thresholds.

The platform is built with Python, spaCy, OCR, Node.js, and React. Its central design principle is that in an audit context, trust matters more than raw detection volume: a tool that produces many unvalidated findings erodes confidence in its results.

Why Continuous Attack Surface Monitoring Matters

The central observation in the abstract is that many serious exposures are not sophisticated attacks but basic hygiene failures that go unnoticed because nobody is watching continuously. An annual penetration test shows your security at one moment. New subdomains, forgotten storage buckets, leaked credentials, and misconfigured services can appear between tests. Continuous monitoring complements periodic testing by surfacing those changes sooner.
